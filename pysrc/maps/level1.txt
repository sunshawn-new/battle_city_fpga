; ===========================================================================
;  level1.txt —— 关卡 1：砖掩体巷战 + 一条河（两个浅滩）+ 树林伏击（入门关）
;
;  坐标系：一个字符 = 一个"块" = 4x4 格 = 20x20 像素。
;          整张地图 30 块 x 30 块（= 120x120 格 = 600x600 像素）。
;          屏幕右边 200px（x = 600..799）是 HUD 信息栏，不占地图像素。
;          map_generator.py 负责展开成根目录的 map.coe（每格一个 tile_id）。
;
;  字符：
;    .  空地(0)      #  砖墙(1) —— 坦克不可过，炮弹打掉 4x2 格
;    S  钢板(2)      ~  河流(3) —— 坦克不可过；炮弹可以飞过去（只挡车不挡弹）
;    T  树林(4)      H  基地(5) —— 坦克不可过，被打中 = 基地被摧毁
;        （树林坦克可以过，只是画面上盖住坦克）
;
;  设计说明（level1）：
;    · 布局是"城市街区"：两条南北主干道（块列 9~10 / 19~20 全程畅通），
;      三路出生点和基地之间永远有 20px 宽的车道连通；掩体是车道之间
;      错落排布的不规则砖岛（2~4 块宽、相邻行错开相位），坦克随时能躲进
;      岛后，通视距离被切碎 —— 不再是一眼望到头的模板砖墙。
;    · 第 8 块行是一条横贯东西的河，浅滩正好开在两条主干道上
;      （块 9~10 / 19~20）。敌人下来必走浅滩，那里就是玩家的伏击点。
;    · 树林带（块行 14 / 21~22）盖住坦克，敌人会从树影里钻出来。
;    · 基地是原版样式的小圈墙：鹰正上方一块 20px 薄砖顶（块 14~15 行 27）+
;      展开器在鹰身上/左/右自动补的一小圈贴墙砖，两侧和正面全敞开，
;      金鹰完整可见 —— 敌人从上方啃穿 25px 就摸到鹰（原版就是这么脆）。
; ===========================================================================
