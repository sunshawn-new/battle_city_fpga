; ===========================================================================
;  level1.txt —— 关卡 1（Battle City 风格，左右对称）
;
;  坐标系：一个字符 = 一个“块” = 4x4 格 = 20x20 像素。
;          整张地图 30 块 x 30 块（= 120x120 格 = 600x600 像素）。
;          屏幕右边 200px（x = 600..799）是 HUD 信息栏，不占地图像素。
;          map_generator.py 负责展开成根目录的 map.coe（每格一个 tile_id）。
;
;  字符：
;    .  空地(0)      #  砖墙(1) —— 坦克不可过，炮弹打掉 4x2 格
;    S  钢板(2)      ~  河流(3) —— 坦克不可过，炮弹消失
;    T  树林(4)      H  基地(5) —— 坦克不可过，被打中 = 基地被摧毁
;        （树林坦克可以过，只是画面上盖住坦克）
;
;  为何墙厚取 1 块（20px）：
;    · 坦克 20x20、砖/钢/河/树的贴图也都是 20x20，1 块厚才不会把贴图切断
;      （旧测试图里有 5px 的薄墙，看着像“半截砖”）。
;    · 炮弹打砖是 20x10，正好半块，打在块边界上永远对齐。
;
;  必须遵守的硬约束（map_generator.py 会校验，违反直接报错）：
;    1. 基地本体固定是 列 56~63 x 行 112~117（8x6 格 = 40x30 像素），
;       因为 vga.v 的 HQ_X0/HQ_Y0 = 290/565 是按这个位置写死的。
;       文件里写 2x2 个 H 块即可：块内落在基地矩形里的格子是 5，
;       剩下的 2 行自动补砖（基地坐在砖砌的台座上）。
;    2. 玩家出生点 (300,300) 上下各 60px 必须空。
;    3. 三个敌人出生点 (40,10)/(300,10)/(560,10) 及其正下方 1 块必须空。
;    4. 从玩家出生点出发，三个敌人出生点、以及基地堡垒左上/右上/上方
;       三个位置都必须能走到（否则坦克会卡在孤岛里）。
;
;  设计说明（关卡 1）：
;    · 第 8~9 块是一条横贯东西的河（40px 宽），左右各留一处 3 块宽的
;      浅滩（第 4~6 块 / 23~25 块）当过河通道：敌人从上方三个出生点下来
;      必须走浅滩，形成天然关隘。
;    · 河下方左右各一组钢板（第 5~6、23~24 块）当掩体；第 18~19 块行
;      再压一组钢板（第 7~8、21~22 块）；第 1~3、26~28 块是树林
;      （坦克能钻，画面上会盖住坦克），可以用来埋伏。
;    · 四角是砖砌的小房子（第 3~4 块行，宽 3 块），底部中央是基地堡垒
;      （顶盖 2 块高 + 两侧 1 块厚 + 2 行台座），堡垒正上方留出 20x20 的
;      冲刺空间（第 24~25 块行）。
;    · 纵向 x = 14~16 块（像素 280~340）是直通堡垒的主通道，正好罩住
;      玩家出生点；通道两侧第 20~23 块行是砖墙，把敌人往中间挤。
; ===========================================================================
