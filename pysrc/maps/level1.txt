; ===========================================================================
;  level1.txt —— 关卡 1：砖墙迷宫 + 一条河（入门关）
;
;  坐标系：一个字符 = 一个“块” = 4x4 格 = 20x20 像素。
;          整张地图 30 块 x 30 块（= 120x120 格 = 600x600 像素）。
;          屏幕右边 200px（x = 600..799）是 HUD 信息栏，不占地图像素。
;          map_generator.py 负责展开成根目录的 map.coe（每格一个 tile_id）。
;
;  字符：
;    .  空地(0)      #  砖墙(1) —— 坦克不可过，炮弹打掉 4x2 格
;    S  钢板(2)      ~  河流(3) —— 坦克不可过；炮弹可以飞过去（只挡车不挡弹）
;    T  树林(4)      H  基地(5) —— 坦克不可过，被打中 = 基地被摧毁
;        （树林坦克可以过，只是画面上盖住坦克）
;
;  为何墙厚取 1 块（20px）：
;    · 坦克 20x20、砖/钢/河/树的贴图也都是 20x20，1 块厚才不会把贴图切断
;      （旧测试图里有 5px 的薄墙，看着像“半截砖”）。
;    · 炮弹打砖是 20x10，正好半块，打在块边界上永远对齐。
;
;  必须遵守的硬约束（map_generator.py 会校验，违反直接报错）：
;    1. 基地本体固定是 列 58~61 x 行 113~116（4x4 格 = 20x20 像素），
;       正好等于 vga.v 那张 20x20 金鹰精灵的包围盒（HQ_X0/HQ_Y0 = 290/565），
;       所以鹰和地图格严丝合缝，不会出现一圈黑缝。
;       文件里写 2x2 个 H 块即可（块 14~15 x 28~29）：块内落在基地矩形里的
;       格子是 5，其余格子自动补砖 —— 砖墙因此是紧贴着基地的。
;    2. 基地上下左右各 1 格必须是砖/钢（它就是上一条自动补出来的那圈），
;       坦克不能直接摸到基地。
;    3. 玩家出生点 (200,560) 上一块 / 上两块必须空（出生就压在堡垒左边的
;       那块空地上，和原版一样贴着老家出生）。
;    4. 三个敌人出生点 (40,0)/(300,0)/(560,0) 及其正下方 1 块必须空。
;    5. 从玩家出生点出发，三个敌人出生点、基地堡垒左/右/正上方三个贴脸
;       位置都必须能开到 —— 用的是 20x20 车身整体的 BFS，不是格子连通。
;
;  设计说明（level1）：
;    · 砖墙用 A/B 两种相位交替：砖墙 3 块厚、走廊 2 块宽，砖墙占全图
;      约 32%（旧版砖墙只占 4%，几乎全是空地）。敌人在走廊里推进，玩家
;      可以贴着墙根躲炮弹，也能打穿砖墙抄近路。
;    · 第 8~9 块是一条横贯东西的河（40px 宽），左侧留 4 块宽的
;      浅滩（第 3~6 块）当过河通道：敌人从上方下来必须走浅滩。
;    · 第 25 块行是玩家出生点那条横向大走廊（出生点上方 60px
;      必须空，坦克才有起步空间）。
;    · 底部中央是基地堡垒：顶盖 2 块高（第 26~27 块行）+ 两侧 1 块厚，
;      堡垒左/右/正上方留出可停车的开阔地当最后防线。
;    · 本关没有钢板：全砖掩体，炮弹能把战场越打越开。
; ===========================================================================
